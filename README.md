# Silicon – Inlämningsuppgift C

Detta projekt är Inlämningsuppgift C och bygger på designen Silicon Design Template.

Projektet har genomförts individuellt.

## Teknik

- HTML
- CSS
- Git
- GitHub

## Sektioner

- Header
- Hero
- Brands
- Features
- How Does It Work
- App Features
- Testimonials
- FAQ
- Subscribe
- Footer


## Arbetssätt

Projektet har versionshanterats med Git. Arbetet har delats upp i olika branches för webbplatsens olika delar och därefter slagits samman till main.

Delar av mitt tidigare arbete från inlämningsuppgift A och B har återanvänts i projektet.

## Design och tillgänglighet

Webbplatsen är byggd med utgångspunkt i Silicon Design Template. HTML har strukturerats med semantiska element och bilder har alt-texter där det är relevant.

Layouten är anpassad för olika skärmstorlekar med CSS media queries. Vissa mindre anpassningar har gjorts för att layouten ska fungera på desktop, tablet och mobil.
